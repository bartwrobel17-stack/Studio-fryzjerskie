# Studio Fryzjerskie

Strona salonu fryzjerskiego we Wrocławiu, przygotowana pod Next.js i Vercel.

## Uruchomienie
1. npm install
2. npm run dev

## Panel właściciela
Wejdź na /admin. Panel pozwala dodawać, edytować, usuwać i porządkować zdjęcia galerii.

Obecna wersja zapisuje dane galerii w localStorage przeglądarki. Przed sprzedażą strony warto podłączyć autoryzację oraz trwały storage/bazę danych.
